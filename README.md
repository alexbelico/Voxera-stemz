# Voxera Stemz

App de iOS para cadenas de separación de audio con MVSEP. El token se escribe en Ajustes y queda en el llavero del dispositivo.

Versión 1.1 (2). El flujo es: lista de cadenas, editar, correr, resultados. Cada paso siguiente sube el stem guardado en el dispositivo. La acción de GitHub genera un IPA sin firmar.
